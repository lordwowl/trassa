# PROGRESS — «Трасса»

## Текущий этап: M1 — Дорога

Цель (`docs/GDD.md`, разделы 5–6): по пустой трассе приятно ехать. Псевдо-3D дорога, физика машины, простая кабина со спидометром, управление touch + tilt.

### Очередь задач M1
- [x] **M1.1** Модель дороги (`core/road`): сегменты, участки с плавным входом, генератор замкнутой трассы по seed, проекция; `RoadRenderer` (псевдо-3D, без аллокаций в кадре)
- [ ] **M1.2** Физика машины (`core/car`): газ/тормоз 0..1, разгон, сопротивление, макс. скорость, центробежный снос в поворотах, руль, обочина (замедление + тряска); тесты
- [ ] **M1.3** Управление (`input/`): педали газа/тормоза справа и слева, руль зонами и наклоном (tilt, калибровка), клавиатура на десктопе
- [ ] **M1.4** Простая кабина: рамка лобового стекла, руль, вращающийся вслед за вводом, стрелочный спидометр; горизонт и обзор под кабину
- [ ] **M1.5** Придорожные объекты (деревья, столбы, знаки) через реестр спрайтов, сортировка по дальности; итоговый тюнинг «приятно ехать»

### Сделано в M1
**M1.1 — дорога и псевдо-3D рендер**
- `core/road`: `types` (сегмент: кривизна 1/м, высота начала, полосы), `builder` (участки enter/hold/leave, easeIn/easeInOut, высоты без разрывов), `generator` (замкнутая трасса по seed: прямые, повороты, холмы, повороты на холмах, S-связки; уклон ≤ `road.maxGrade`, высота не уходит дальше ±2·`hillMax`, в конце плавный возврат к 0), `query` (`wrapZ`, `segmentIndexAt`, `heightAt`), `projection` (`focalFromFov`, `project` без аллокаций). Тесты: 10 новых, всего 34.
- `render/road/RoadRenderer.ts`: проход вперёд проецирует сегменты в предвыделенные `Float32Array` и отсекает скрытые за холмом и тоньше пикселя у горизонта, проход назад рисует от дальних к ближним: трава, «зебра» обочины, полотно, пунктир между полосами. Палитры день/ночь.
- `DriveScene`: трасса по `seed` (отдельный поток RNG `road:<seed>`), камера на высоте глаз; машина пока сама разгоняется по центру дороги (до M1.2).
- `tuning.json`: `render.horizon`, `road.laneWidth`, `road.curveMax`, `road.hillMax`, `road.maxGrade`, `road.trackLength`. Параметры с пометкой «(новая трасса)» применяются при следующем входе в сцену езды («Назад» → «Играть»).
- Профиль в headless Chromium: JS-часть кадра ~1% времени; FPS в headless (~15) ограничен программной растеризацией и для телефона не показателен.

### Как проверить на телефоне (M1.1)
- https://lordwowl.github.io/trassa/?debug=1&scene=drive&seed=7 — трасса с поворотами и холмами, разметка и «зебра» бегут, на подъёмах дорога уходит за гребень без мерцания и щелей.
- Ночь: https://lordwowl.github.io/trassa/?debug=1&scene=drive&seed=7&time=22
- В панели «⚙ Тюнинг»: «Макс. скорость» и «Разгон» — быстрее доехать до поворотов; «Угол обзора», «Высота камеры», «Линия горизонта», «Ширина полосы», «Дальность прорисовки» меняют картинку сразу. Для «новая трасса»-параметров (кривизна, холмы, уклон, длина) выйти «Назад» и снова «Играть».
- Другой seed — другая трасса: `seed=1`, `seed=11`, …
- Посмотреть FPS в оверлее на телефоне и написать, сколько показывает при «Дальность прорисовки» 300 — это ориентир для оптимизаций.

### Известные проблемы M1
- Руля и физики пока нет: машина едет по центру, `x` в оверлее всегда 0 (M1.2–M1.3).
- `render.resolutionScale` всё ещё не применяется (запланировано вместе с кабиной, M1.4).

### Как проверить на телефоне (M0)
Сначала (один раз) включить Pages: **Settings → Pages → Source: GitHub Actions**, и **Settings → Actions → General → Workflow permissions: Read and write** (см. `docs/GITHUB_SETUP.md`, раздел 3).

После мержа в `main` дождаться зелёных «Deploy to GitHub Pages» и «Android debug APK» во вкладке Actions.
- Меню: https://lordwowl.github.io/trassa/ → «Играть» включает весь экран и альбомную ориентацию, открывается сцена езды; «Карта» и «Город» открывают заглушки, «Назад» возвращает в меню.
- Debug: https://lordwowl.github.io/trassa/?debug=1&scene=drive&seed=123&weather=rain&time=14&money=500 → слева сверху FPS и телеметрия (seed 123, rain, 14:00, money 500); справа кнопка «⚙ Тюнинг» → слайдеры; подвигать «Дальность прорисовки» / «Угол обзора» / «Макс. скорость» — дорога меняется сразу; перезагрузить страницу — значения сохранились; «Скопировать JSON» → вставить в чат.
- Ночь: https://lordwowl.github.io/trassa/?debug=1&scene=drive&time=22 → тёмное небо.
- Неверные параметры: https://lordwowl.github.io/trassa/?debug=1&weather=lava → в оверлее строка `! weather: неизвестная погода «lava»`.
- Портретная ориентация в браузере → надпись «Поверните телефон горизонтально».
- APK: Releases → `Debug build N` → установить → приложение «Трасса» открывается горизонтально, без статус-бара.

### Известные проблемы M0
- Бандл Phaser ~1.2 МБ (330 КБ gzip) одним чанком — для M0 нормально, Vite выводит только информацию о размере.
- Иконка и splash приложения — стандартные от Capacitor; заменить, когда появится арт.
- Параметр `render.resolutionScale` пока ни на что не влияет (см. M1.4).
- `screen.orientation.lock` не работает в iOS Safari и на десктопе — там просто ничего не происходит.

## Общее

### Зависимости и причины
- `phaser` — игровой движок (стек проекта).
- `@capacitor/core`, `@capacitor/android`, `@capacitor/cli` (dev) — упаковка в APK; `core` также нужен для `Capacitor.isNativePlatform()` (в APK не трогаем fullscreen API браузера).
- `vite` (dev) — сборка и dev-сервер.
- `typescript` (dev) — типизация, `tsc --noEmit`.
- `vitest` (dev) — тесты логики `core/`.
